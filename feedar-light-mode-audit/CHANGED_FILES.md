# فایل‌های تغییرکرده در این کار

- `feedar-demo/src/styles/theme.css`: توکن‌های Light Mode و اصلاح‌های موضعی کنترل، دکمه، جدول، Telepresence و Kiosk. این فایل پیش از ممیزی نیز تغییرات ثبت‌نشدهٔ مربوط به theme داشت؛ حفظ شدند.
- `feedar-demo/e2e/theme.spec.ts`: انتظار رنگ panel مطابق سطح جدید `#fbfcfe` شد. تست‌های theme موجود حفظ شدند.
- `feedar-demo/index.html`: پیوند favicon با `BASE_URL`.
- `feedar-demo/public/favicon.svg`: آیکون سادهٔ SVG برای حذف خطای ۴۰۴.
- `feedar-demo/docs/FEATURE_CHECKLIST.md`: ثبت فقط بررسی‌های انجام‌شده و محدودیت‌ها.
- `feedar-light-mode-audit/`: گزارش‌ها، manifestها، اسکریپت capture و تصاویر قبل/بعد.

دیگر تغییرات ثبت‌نشدهٔ موجود در مخزن مربوط به کارهای پیشین هستند و عمداً حفظ شدند. commit، push و deploy انجام نشد.
