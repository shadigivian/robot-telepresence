# محدودیت‌های باقی‌مانده

- Node 24 LTS در این ماشین موجود نبود؛ اجرای واقعی با Node 26.5.1 و npm 11.17.0 انجام شد.
- فقط Google Chrome نصب‌شده اجرا شد؛ Firefox، WebKit و مرورگرهای دستگاه واقعی بررسی نشدند.
- هفت اندازهٔ درخواستی برای صفحات اصلی ذکرشده بررسی شد؛ همهٔ زیرصفحه‌ها و همهٔ حالت‌های hover/loading/error در هر هفت اندازه ثبت نشدند. سایر مسیرهای اصلی در لپ‌تاپ و تعدادی در موبایل ثبت شدند.
- داده‌های زندهٔ شبیه‌ساز باعث تغییر بسیار کوچک در یک تصویر Dark Robot Status می‌شوند؛ مقایسهٔ پیکسلی آن snapshot پایدار نیست.
- ممیزی کنتراست روی جفت‌رنگ‌های اصلی انجام شد و جایگزین ممیزی جامع WCAG یا screen reader نیست.
- هیچ VPS، استقرار عمومی، origin واقعی Boss/App یا سخت‌افزار ربات بررسی نشد. این نسخهٔ مرورگری داده و رفتار شبیه‌سازی‌شده دارد.
