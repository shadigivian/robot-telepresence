# رنگ‌های Light Mode، قبل و بعد

| توکن | قبل | بعد | هدف |
| --- | --- | --- | --- |
| Background | `#f3f6fa` | `#f6f8fb` | زمینهٔ آرام‌تر |
| Panel | `#ffffff` | `#fbfcfe` | کاهش سفیدی سطوح بزرگ |
| Secondary | `#e9eff6` | `#edf1f5` | سطح مکمل خنثی‌تر |
| Field | `#f8fafc` | `#f7f9fc` | ورودی هماهنگ |
| Text | `#172a40` | `#243247` | متن اصلی ملایم و خوانا |
| Secondary text | مقدار قبلی در CSS | `#45566b` | خوانایی پایدار |
| Muted | مقدار قبلی در CSS | `#53657b` | افزایش وضوح توضیحات |
| Teal | `#087d80` | `#117980` | اشباع کمتر |
| Blue | `#4268ca` | `#4169b5` | دکمهٔ اصلی آرام‌تر |
| Border | `#d7e1ec` | `#d9e2ec` | مرز سطوح |
| Control border | مرز بسیار کم‌رنگ | `#8193a8` | تشخیص فیلدها |
| Shadow | `0 12px 40px rgba(26,56,82,.09)` | `0 10px 30px rgba(36,50,71,.055)` | سایهٔ ملایم‌تر |

دکمهٔ اصلی در Light Mode از گرادیان درخشان به آبی یکدست تغییر یافت. سطوح دوربین، نقشه و Kiosk همچنان تیره و عمدی هستند. توکن‌های Dark Mode تغییر نکردند.
