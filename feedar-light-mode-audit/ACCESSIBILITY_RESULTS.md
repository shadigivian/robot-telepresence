# بررسی دسترس‌پذیری بصری

نسبت‌های زیر از رنگ‌های نهایی CSS با فرمول WCAG محاسبه شده‌اند؛ سنجش برای ترکیب‌های مشخص است، نه گواهی جامع WCAG برای تمام اجزا.

| ترکیب | نسبت | معیار مرتبط |
| --- | ---: | --- |
| متن اصلی روی panel | 12.61:1 | متن عادی ≥4.5 |
| متن ثانویه روی panel | 7.32:1 | متن عادی ≥4.5 |
| متن muted روی panel | 5.82:1 | متن عادی ≥4.5 |
| teal روی panel | 5.03:1 | متن عادی ≥4.5 |
| blue روی panel | 5.23:1 | متن عادی ≥4.5 |
| سفید روی دکمهٔ آبی | 5.37:1 | متن عادی ≥4.5 |
| مرز فیلد روی panel | 3.07:1 | مرز کنترل ≥3 |
| متن Kiosk روی فیلد تیره | 14.76:1 | متن عادی ≥4.5 |
| مرز فیلد Kiosk روی زمینهٔ فیلد | 3.67:1 | مرز کنترل ≥3 |
| مرز فیلد قبلی روی زمینهٔ قبلی | 1.26:1 | کمتر از 3؛ اصلاح شد |

Playwright وجود برچسب/آیکون Robot Status، focus فرم، persist شدن theme، اندازه‌های موبایل و نبود سرریز افقی را بررسی کرد. قاعدهٔ `prefers-reduced-motion` موجود حفظ شد و captureها با reduced motion انجام شدند. وضعیت ربات فقط با رنگ منتقل نمی‌شود و متن/آیکون دارد. آزمون کامل screen reader، پیمایش کامل صفحه‌کلید و همهٔ ترکیب‌های پویا انجام نشده است.
