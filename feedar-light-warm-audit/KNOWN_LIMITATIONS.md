# محدودیت‌ها

- آزمون با Node 26.5.1 انجام شد؛ Node 24 LTS خواسته‌شده در این ماشین موجود نبود.
- Chrome نصب‌شده اجرا شد؛ Firefox، WebKit و دستگاه فیزیکی بررسی نشدند.
- هفت اندازه برای هفت گروه صفحهٔ اصلی و Login بررسی شد؛ همهٔ زیرصفحه‌ها، همهٔ dropdownها و همهٔ حالت‌های hover/loading/error در تمام اندازه‌ها بررسی نشدند.
- دعوت‌نامه، suspend و جریان‌های دیگر در suite موجود اجرا شدند، اما capture سفارشیِ قبل/بعد برای تک‌تک آن‌ها وجود ندارد.
- انقضای هشت‌ساعتهٔ هویت و رفتار Forgot password به‌صورت جداگانه بررسی نشد؛ دکمهٔ Forgot password در Demo Login وجود ندارد.
- صفحه‌های operational Boss/Organization فقط در Build آزمایشی روی دو Origin محلی آزمایش شدند. هیچ دامنهٔ واقعی، VPS یا احراز هویت Production بررسی نشد. IndexedDB بین دو Origin مستقل است.
- نسبت‌های کنتراست برای جفت‌های رنگ منتخب محاسبه شدند؛ ارزیابی جامع WCAG و screen reader انجام نشد.
- اختلاف کوچک یک تصویر Dark Robot Status ناشی از دادهٔ زمان‌دار شبیه‌ساز است؛ این snapshot برای مقایسهٔ پیکسلی کاملاً پایدار نیست.
- هیچ عملکرد ربات فیزیکی، تماس واقعی، یا سرویس AI واقعی در این ممیزی اعتبارسنجی نشد.
