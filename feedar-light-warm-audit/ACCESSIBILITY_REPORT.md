# نتیجهٔ بررسی کنتراست و دسترسی

نسبت‌های زیر از رنگ‌های نهایی CSS با فرمول WCAG محاسبه شدند. این بررسی ترکیب‌های مشخص است و گواهی کامل WCAG برای همهٔ اجزا نیست.

| جفت رنگ | نسبت |
| --- | ---: |
| متن اصلی / کارت | ۱۲٫۱۸:۱ |
| متن ثانویه / کارت | ۷٫۰۸:۱ |
| متن muted / کارت | ۵٫۶۴:۱ |
| آبی برند / کارت | ۵٫۰۶:۱ |
| فیروزه‌ای برند / کارت | ۴٫۸۷:۱ |
| سفید / دکمهٔ آبی | ۵٫۳۷:۱ |
| مرز کنترل / زمینهٔ ورودی | ۳٫۱۲:۱ |
| متن ناوبری / Sidebar | ۶٫۲۲:۱ |

فوکوس فرم ساخت سازمان در [تصویر نهایی](screenshots/after/light-boss-create-org-dialog-focus-laptop.png) مشخص است. Login با صفحه‌کلید از طریق Enter ارسال شد؛ نمایش/مخفی کردن رمز و خطاها بررسی شدند. برچسب و آیکون Robot Status باقی ماندند و وضعیت فقط به رنگ وابسته نیست. captureها با `reducedMotion:'reduce'` انجام شدند. آزمون جامع screen reader یا پیمایش صفحه‌کلید در تک‌تک مسیرها انجام نشد.
