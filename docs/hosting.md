# میزبانی دائمی

صفحات GitHub Pages ثابت‌اند؛ ورود، چت و تماس به بک‌اند روشن نیاز دارند. تونل موقت لپ‌تاپ برای آزمایش است و تضمین اتصال دائمی ندارد. میزبانی ابری بک‌اند را از روشن بودن لپ‌تاپ مستقل می‌کند؛ خود ربات و مرورگر Robot Station برای تصویر و Arduino باید روشن باشند.

## مسیر پیشنهادی: Render

1. در https://dashboard.render.com/register حساب بسازید و GitHub را متصل کنید.
2. New → Blueprint را انتخاب و مخزن `shadigivian/robot-telepresence` را وارد کنید. فایل `render.yaml` یک سرویس Docker با پلن **Starter** و دیسک ۱ گیگابایت آماده کرده است. هزینه نمایش‌داده‌شده را قبل از Create بررسی کنید؛ این فایل هیچ خریدی خودکار انجام نمی‌دهد. پلن Free پس از ۱۵ دقیقه بی‌کاری خاموش می‌شود و دیسک دائمی ندارد.
3. مقدار خصوصی `TURN_CREDENTIALS_URL` مربوط به Metered را فقط در Environment پنل قرار دهید؛ آن را در GitHub یا `public/config.js` نگذارید. سرویس یک نشانی HTTPS ثابت `*.onrender.com` می‌گیرد.
4. برای نصب جدید، در Shell سرویس، `ADMIN_PASSWORD` حداقل ۱۲ کاراکتری را موقتاً تنظیم کنید، `npm run setup` اجرا و سپس متغیر رمز را حذف کنید. برای حفظ نصب فعلی، فایل خصوصی `data/site.json` را از مسیر امن به `/app/data/site.json` منتقل کنید؛ setup را روی داده‌های موجود اجرا نکنید. فایل حاوی هش حساب‌ها و اطلاعات خصوصی است و نباید commit شود.
5. با نشانی همان سرویس، `https://YOUR-SERVICE.onrender.com/portal.html` را باز کنید. سایر صفحات: `/robot.html` و `/user.html`. اگر GitHub Pages هم استفاده می‌کنید، `apiBase` را روی نشانی سرویس تنظیم و `apiDiscoveryUrl` را خالی کنید؛ سپس صفحات را با `node deploy.js` منتشر کنید. تونل موقت نباید نشانی ثابت را بازنویسی کند؛ اتصال registry را در نسخه دائمی غیرفعال نگه دارید.
6. Robot Station را روی لپ‌تاپ ربات باز کنید، وارد حساب دستگاه شوید و اجازه دوربین/میکروفن بدهید. برای Arduino USB از Chrome یا Edge دسکتاپ استفاده کنید. ورود، چت و تماس از مرورگرهای پشتیبان WebRTC روی HTTPS در دسترس‌اند.

منابع: https://render.com/docs/free ، https://render.com/docs/web-services ، https://render.com/docs/disks

راه‌اندازی واقعی تا ساخت حساب و دریافت نشانی سرویس کامل نیست. پلن پولی هم اتصال صددرصد بدون وقفه هنگام تعمیرات یا استقرار مجدد را تضمین نمی‌کند. از دیسک و `site.json` نسخه پشتیبان نگه دارید و فقط یک نمونه سرور اجرا کنید؛ چت/حساب‌ها روی دیسک و تماس‌های فعال در حافظه سرور هستند.
