# ممیزی رابط Feedar

تاریخ: ۲۰۲۶-۱۰-۱۹. محدوده: بستهٔ `feedar-demo/`، بدون تغییر در برنامهٔ Node قدیمی، سرور یا سخت‌افزار.

## یافته‌ها و اصلاح‌ها

- تم روشن/تیره فقط در `OperationalLoginPage` نگه‌داری می‌شد؛ صفحات داخلی، ورود توسعه‌ای و صفحات عمومی از آن پیروی نمی‌کردند. اکنون `ThemeProvider` ریشهٔ برنامه را کنترل می‌کند و کل مسیرها توکن‌های مشترک دارند.
- رنگ‌های ثابت تیره در CSS مشترک، مدیریت و Fleet باعث زمینه و متن نامتناسب در حالت روشن می‌شدند. رنگ‌های پایهٔ عملکردی به متغیرهای معنایی منتقل و برای پوسته، فرم، کارت، جدول، نشان وضعیت، اعلان و صفحهٔ عمومی تنظیم روشن افزوده شدند. صحنهٔ دوربین، نقشه و سطح Kiosk عمداً زمینهٔ تیرهٔ قابل‌خواندن دارند.
- وضعیت Robot Status برای اتصال، فعالیت، دسترسی، باتری و کاربران متصل عمدتاً متن ساده بود. نشان‌های SVG هم‌سبک با برچسب متنی و رنگ معنایی افزوده شد.
- جدول Robot Status در موبایل پیمایش افقی داشت. اکنون در عرض حداکثر ۷۶۰ پیکسل هر ربات به کارت برچسب‌دار تبدیل می‌شود.
- وضعیت خالی از آیکون اختصاصی Bot استفاده می‌کرد؛ از نشانهٔ مشترک وضعیت خالی استفاده می‌کند. حرکت محدود برای اعلان، پنجره و نشان زنده افزوده شد.

## بخش‌های بازبینی‌شده

ورود توسعه‌ای، داشبورد Boss، پنل سازمان، Robot Status و Telepresence در اندازهٔ دسکتاپ/موبایل و دو تم تصویربرداری شدند. مجموعهٔ Playwright مسیرهای Boss، نقش‌های سازمان، پشتیبانی، نشست، ربات، صفحات عمومی و چند اندازهٔ نمایش را نیز اجرا می‌کند. تصاویر در `screenshots/` هستند.

ساختار مسیریابی، داده‌ها، دسترسی نقش‌ها و رفتار کنترل ربات تغییر نکرده‌اند. رنگ‌های صحنهٔ سه‌بعدی نمایشی و ناحیهٔ ویدئو به عنوان محتوای تصویری حفظ شدند.
