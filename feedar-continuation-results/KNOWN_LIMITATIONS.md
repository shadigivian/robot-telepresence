# محدودیت‌ها

- این نسخه فقط دمو و ذخیره‌سازی IndexedDB همان مبدأ است؛ push مستقل، سرور پشتیبانی، اتصال ویدیویی واقعی و ربات فیزیکی ندارد.
- Identity و نقش‌ها در مرورگر نمایشی‌اند؛ امنیت چندمستأجری تولیدی به backend نیاز دارد.
- تیکت قدیمی بدون مرجع معتبر سازمان محفوظ ولی برای عملیات Boss قابل انتساب نیست. مدیریت آن مستلزم تعیین مالکیت معتبر است.
- وضعیت‌های قدیمی تیکت برای سازگاری داده‌ای باقی مانده‌اند و عنوان UI به Open/In Progress/Waiting for User تبدیل می‌شود.
- تصاویر فقط Chrome نصب‌شده را پوشش می‌دهند؛ Firefox/WebKit و سخت‌افزار اجرا نشدند.
- Node 24 LTS توصیهٔ پروژه است؛ محیط حاضر Node 26.5.1 داشت.
