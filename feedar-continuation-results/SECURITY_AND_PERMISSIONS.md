# مجوزها و محدودیت امنیتی

مجوزها در `src/domain/permissions.ts` و دوباره در `src/services/demo/service.ts` بررسی می‌شوند. User تیکت خود و ربات منتسب را می‌بیند؛ Admin/Owner فقط دادهٔ سازمان خود؛ Boss تیکت‌های لینک‌شدهٔ همهٔ سازمان‌ها را از پنل مرکزی می‌بیند. شناسهٔ سازمان/نویسنده در ساخت تیکت از actor و عضویت معتبر گرفته می‌شود. تغییر ID تیکت یا درخواست در فراخوانی مستقیم سرویس نیز بررسی می‌شود. اعلان جهانی تیکت فقط برای Boss است؛ اعلان بازدیدکننده فقط برای کارمند هدف.

این سیاست فقط نمایشی و داخل مرورگر است. sessionStorage هویت دمو و IndexedDB داده را نگه می‌دارد؛ هیچ backend امن یا احراز هویت تولیدی وجود ندارد. دادهٔ کیوسک محدود به نام/ID کارکنان فعال منتسب برای انتخاب عمومی است؛ ایمیل در نسخهٔ عمومی حذف شده است.
