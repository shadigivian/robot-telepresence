# Robot Status و نشست‌ها

منبع کنترل‌کنندهٔ فعلی `robotControlStatus` در `src/domain/robot-status.ts` است: grant با وضعیت `granted`، نسل ربات مطابق، زمان معتبر، session متصل و معتبر، کاربر و عضویت فعال و انتساب ربات. Pending یا درخواست بازدیدکننده هرگز Busy ایجاد نمی‌کند. نام آخرین کنترل‌کننده از grant تاریخی دارای شواهد اعطای واقعی گرفته می‌شود؛ پس از آزادسازی باقی می‌ماند. Busy پس از پایان lease پاک می‌شود و Available فقط برای ربات آماده محاسبه می‌شود.

`src/features/org-robots.tsx` برای User فقط دادهٔ scope شده را نشان می‌دهد؛ Admin/Owner سازمان را کامل می‌بیند. `src/features/boss.tsx` نمایش سراسری را از همان تابع می‌گیرد. `src/features/session.tsx` نیز از همان وضعیت استفاده می‌کند. سناریوهای کنترل انحصاری، لغو pending، refresh، Boss و آخرین کاربر در تست‌های پیشین حفظ و دوباره اجرا شدند. این نتایج فقط شبیه‌ساز مرورگر را تأیید می‌کنند.
