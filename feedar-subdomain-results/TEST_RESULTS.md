# نتیجهٔ آزمون‌های اجراشده

تاریخ: ۱۶ اکتبر ۲۰۲۶. محیط: macOS arm64، Node 26.5.1، Chrome نصب‌شده. نسخهٔ توصیه‌شدهٔ پروژه Node 24 LTS است و در این محیط در دسترس نبود.

| بررسی | نتیجه |
| --- | --- |
| `npm run typecheck` | موفق |
| `npm run lint` | موفق؛ ۰ خطا، ۰ هشدار پس از اصلاح import |
| `npm test` | ۸۷ موفق، ۰ ناموفق، ۱۰ فایل |
| `PLAYWRIGHT_CHANNEL=chrome npm run test:e2e -- --workers=1` | ۳۰ موفق، ۰ ناموفق |
| `PLAYWRIGHT_CHANNEL=chrome npm run test:static` | موفق برای `/` و `/base-check/`؛ فایل‌ها، هدایت مسیر محافظت‌شده، Refresh و حذف Demo Preview |
| Build با Originهای Boss/App/API محلی | موفق |
| بررسی مرورگر روی دو Origin | ورود جداگانه، نبود کنترل‌های دمو، جلوگیری از مسیر محافظت‌شده، Refresh و نبود خطای صفحه؛ دسکتاپ 1440×900 و موبایل 390×844 |
| `git diff --check` | موفق |

تست ایستا ابتدا پس از حذف Demo Preview شکست خورد؛ اسکریپت با رفتار Build عملیاتی هماهنگ شد. اجرای بعدی نشان داد مسیرهای دمو در Build بدون Origin تنظیم‌شده هنوز در دسترس بودند؛ router و DemoProvider به توسعهٔ محلی محدود شدند و بررسی ایستا دوباره موفق شد. تست‌های مرورگر روی Originهای محلی با یک Build مشترک انجام شدند. تصاویر در `screenshots/` هستند.

ورود واقعی، نشست مشترک، انتقال Boss و تبادل دادهٔ دو ساب‌دامین آزمون موفق ندارند؛ Backend لازم برای آن‌ها در این بسته وجود ندارد. آزمایش سخت‌افزار یا VPS انجام نشد.
