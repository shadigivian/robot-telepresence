# محدودیت‌های مانده

- هیچ backend مشترک یا سرویس احراز هویت عملیاتی در بستهٔ static دمو وجود ندارد. ورود واقعی در Originهای Boss/App و انتقال Boss به سازمان عمداً غیرفعال است؛ این بخش‌ها تکمیل‌شده محسوب نمی‌شوند.
- دادهٔ IndexedDB بین ساب‌دامین‌ها مشترک نیست. تیکت، اعلان، وضعیت ربات و اعتبار دمو فقط روی مبدأ همان مرورگر همگام می‌شوند.
- `.env.example` آدرس‌های نمونه دارد؛ DNS، TLS، API، CORS/کوکی و سیاست جلسه برای انتشار واقعی باید تنظیم شوند.
- Chrome بررسی شد؛ Firefox/WebKit، VPS و سخت‌افزار اجرا نشدند.
- محیط این اجرا Node 26.5.1 داشت، در حالی که بسته Node 24 LTS را توصیه می‌کند.
