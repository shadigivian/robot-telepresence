# گزارش حفظ ظاهر

تصاویر ۱۲ نمای مبنا در `screenshots/before/` و ۱۲ نمای پس از اجرا در `screenshots/after/` هستند؛ هر شش بخش در ۱۴۴۰×۹۰۰ و ۳۹۰×۸۴۴ ثبت شدند. مبنا نزدیک‌ترین صفحهٔ سازمانی قبلی است، زیرا شش صفحهٔ جدید پیش‌تر وجود نداشتند؛ بنابراین مقایسهٔ پیکسل‌به‌پیکسل معتبر نیست.

پوستهٔ تیره، فونت، رنگ/گرادیان، sidebar، کارت، جدول، دکمه، modal و آیکون‌های Feedar حفظ شدند. تغییر آشکارِ مورد انتظار: ده لینک مشترک سازمان به شش لینک خواسته‌شده تبدیل شده و محتوای صفحه‌ها از فرم‌ها و جدول‌های جدید تشکیل شده است. CSS عمومی بازطراحی نشد؛ فقط ورودی‌های file در کنترل‌های Upload به صورت بصری پنهان شدند تا دکمهٔ موجود نمایش داده شود.

تست Chrome برای هر شش صفحه در دو اندازه سرریز افقی نداشت و خطای صفحه ثبت نکرد. تصاویر Boss/User/Robot قبلی و تست‌های موجود نیز بدون شکست باقی ماندند. Safari/Firefox/WebKit و مقایسهٔ خودکار تصویری انجام نشدند. نوار `Demo preview` در تصاویر توسعه روی محتوا شناور است و در مبنا نیز وجود داشت.

Robot Status اکنون ستون‌های مستقل Current Connected User و Last Connected User دارد. در دسکتاپ ۱۴۴۰×۹۰۰ هر دو آشکارند؛ در موبایل ۳۹۰×۸۴۴ جدول در همان قاب افقی اسکرول می‌شود و تست مرورگر دسترسی به سلول کاربر فعلی را تأیید کرد. پوسته و سبک CSS تغییر نکرد.
