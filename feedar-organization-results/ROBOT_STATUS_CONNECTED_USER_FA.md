# تکمیل نمایش کاربر متصل در Robot Status

تاریخ بررسی: ۱۴ اکتبر ۲۰۲۶. مبنا: همان worktree و تغییرات قبلی پنل Organizations؛ فایل‌های موجود بازنشانی نشدند.

## رفتار نهایی

- هر ردیف Robot Status نام/شناسهٔ ربات، Online/Offline، فعالیت Working/Idle، دسترسی Available/Busy/Unavailable، باتری، آخرین زمان اتصال شبیه‌سازی‌شده، **Current Connected User**، **Last Connected User** و اتصال به ربات را جداگانه نشان می‌دهد.
- Current Connected User فقط از `ControlGrant` در وضعیت `granted` استخراج می‌شود، به شرط معتبر بودن زمان اجاره، نسل ربات، نشست `connected` و منقضی‌نشده، هویت فعال، عضویت معتبر و تخصیص User به ربات. نام از رکورد User و `@username` از Membership همان سازمان می‌آید. درخواست `pending` کاربر فعلی محسوب نمی‌شود.
- هنگام کنترل معتبر، دسترسی Busy است و Connect to Robot ارائه نمی‌شود. پس از `control.release`، `session.end`، انقضا یا لغو مجوز، نام فعلی حذف و نام کنترل‌کنندهٔ قبلی از تاریخچهٔ اجارهٔ موفق نمایش داده می‌شود. نبود کنترل‌کننده با `No active user` و نبود سابقه با `No previous user` مشخص است.
- Telepresence از همان تابع مشتق‌شده برای وضعیت دسترسی و مجاز بودن کنترل استفاده می‌کند. درخواست نشست تازه در حالت Busy غیرفعال است؛ کنترل‌های مدیریتی نشست موجود باقی می‌مانند. کاربر می‌تواند درخواست کنترل pending خود را لغو کند.
- مقدار `grantedAt` اختیاری به ControlGrant افزوده شد تا تاریخچهٔ کنترل موفق از درخواست‌های صرفاً pending جدا بماند؛ snapshotهای قدیمی همچنان قابل خواندن‌اند. هیچ migration مخربی اجرا نشد.

## شواهد آزمون

- ۴ تست واحد جدید: درخواست منتظر، کنترل فعال/رهاسازی/پایان، رقابت و لغو pending، انقضای اجاره؛ همگی گذشتند.
- ۲ تست Playwright جدید: Owner و Boss نام و نام کاربری کنترل‌کننده را از دو تب می‌بینند؛ پس از Refresh، Release و End Call مقدار صحیح می‌ماند؛ رقیب نمی‌تواند کنترل را بگیرد و لغو pending کنترل فعال را قطع نمی‌کند. هر دو گذشتند.
- دسترسی User به ربات‌های تخصیص‌نداده‌شده و مستأجر دیگر در تست‌های قبلی suite نیز گذشت. نمای موبایل ۳۹۰×۸۴۴ با اسکرول داخلی جدول به ستون کاربر فعلی دسترسی دارد و صفحه سرریز افقی ندارد. نمای دسکتاپ ۱۴۴۰×۱۰۰۰ بررسی شد.

این نتایج فقط شبیه‌ساز و مرورگر محلی را تأیید می‌کنند؛ هیچ ربات فیزیکی یا سرویس backend آزمایش نشد.
