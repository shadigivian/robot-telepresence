# نتایج اجرای آزمون

۱۴ اکتبر ۲۰۲۶، شاخه `feedar-demo`، مبنای commit `b873771`، macOS arm64. Node 26.5.1 و npm 11.17.0 در دسترس بودند؛ نسخه‌های درخواست‌شدهٔ Node 24 LTS و npm 11.21.0 در این محیط موجود نبودند.

| دستور از `feedar-demo/` | نتیجهٔ نهایی |
| --- | --- |
| `npm run typecheck` | گذشت |
| `npm run lint` | گذشت، بدون خطا/هشدار lint |
| `npm test` | ۸ فایل، ۸۱ تست گذشت، ۰ شکست، ۰ ردشده |
| `npm run build` | گذشت؛ فقط هشدار غیرمسدودکنندهٔ bundle برای directive `use client` وابستگی‌ها |
| `PLAYWRIGHT_CHANNEL=chrome npm run test:static` | گذشت در `/` و `/base-check/`: asset، مسیر عمومی مستقیم، تازه‌سازی kiosk، لینک تولیدشده |
| `PLAYWRIGHT_CHANNEL=chrome npm run test:e2e -- --workers=1` | ۲۷ سناریو گذشت، ۰ شکست، ۰ ردشده |

سه نقص کنترل گزارش‌شده پیش از اصلاح با تست رگرسیون بازتولید شدند. پس از اصلاح، چهار تست ایمنی اختصاصی، شامل لغو درخواست منتظر در حضور کنترل‌کنندهٔ دیگر، گذشتند. تست مرورگر جریان‌های Boss/Owner/Admin/User، ثبت و جفت‌سازی registry، ورود و بازگشت Boss، دپارتمان، PDF/لوگو، دعوت کارمند، مجوز ربات، status، session، اعتبار، تیکت، راهنمای محلی، جداسازی مستأجر، بازخوانی، همگام‌سازی دو تب و نبود page error را پوشش داد.

تصاویر قبل/بعد شش بخش در ۱۴۴۰×۹۰۰ و ۳۹۰×۸۴۴ زیر `screenshots/` ثبت شدند. تست‌های قبلی Surface landscape ۱۳۶۸×۹۱۲، portrait ۹۱۲×۱۳۶۸ و چند اندازهٔ دیگر را نیز پوشش دادند. فقط Chrome نصب‌شده اجرا شد؛ Firefox/WebKit و سخت‌افزار فیزیکی اجرا نشد. CDN مرورگر بسته‌ای Playwright در این منطقه ۴۰۳ می‌داد و `PLAYWRIGHT_CHANNEL=chrome` استفاده شد. یک اجرای اولیهٔ `test:static` در sandbox با EPERM برای localhost متوقف شد؛ اجرای مجاز نهایی گذشت. شکست‌های میانی locator و فرم تلفن سازمان برطرف شدند و در نتایج نهایی باقی نماندند.

## ادامهٔ Robot Status

پس از افزودن نمایش کنترل‌کنندهٔ فعلی/اخیر، چهار تست واحد و دو سناریوی Chrome اختصاصی اضافه شدند. شمار نهایی: ۸۱ تست واحد و ۲۷ تست Playwright موفق؛ صفر شکست و صفر ردشده. سناریوهای جداگانهٔ موبایل برای دسترسی به ستون کاربر فعلی در جدول اسکرول‌پذیر نیز اجرا شدند. جزئیات در `ROBOT_STATUS_CONNECTED_USER_FA.md` است.
