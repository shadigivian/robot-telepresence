# خلاصهٔ پیاده‌سازی پنل سازمان‌ها

تاریخ: ۱۴ اکتبر ۲۰۲۶. شاخه `feedar-demo`، مبنای commit `b873771`. کار فقط در نسخهٔ محلی انجام شد؛ commit، push، deploy و تماس با VPS انجام نشد. تغییرات ثبت‌نشدهٔ پیشین حفظ شدند.

- شش بخش دقیق سازمان با پوسته و اجزای موجود Feedar افزوده شد. پنل مرکزی Boss همچنان پنج بخش خود را نشان می‌دهد و Boss با هویت خودش وارد سازمان می‌شود و بازمی‌گردد.
- اطلاعات سازمان، دپارتمان، معرفی/قوانین/PDF، لوگو، کارمند و مجوز، مدیریت/وضعیت ربات و پشتیبانی در IndexedDB محلی به هم متصل‌اند.
- wizard جفت‌سازی registry، SessionPage، CreditLedger، invitation، knowledge منتشرشده و کنترل شبیه‌ساز استفادهٔ مجدد شدند.
- دادهٔ ربات و نام آن با registry مرکزی هماهنگ می‌شود؛ لغو تخصیص، registry و تاریخچه را نگه می‌دارد.
- نقص‌های توقف در `control.deny`، لغو دیرهنگام، پایان دوبارهٔ جلسه و release یک درخواست منتظر اصلاح و با تست رگرسیون پوشش داده شدند.
- داشبورد سازمانی قدیمی و ده لینک مربوطه از ناوبری سازمان پنهان شدند؛ مسیرها و سرویس‌های مشترک برای نقش‌های دیگر و صفحه‌های عمومی حذف نشدند.

این پیاده‌سازی یک دموی ایستا و مرورگرمحور است. هویت، اعتبار، تیکت، دستیار و کنترل ربات همگی محلی/شبیه‌سازی هستند.

## ادامهٔ Robot Status

Current Connected User و Last Connected User اکنون از اجاره‌های کنترل و نشست معتبر مشتق می‌شوند؛ نام کاربری در صورت ثبت نمایش داده می‌شود. Pending، پایان/انقضا و آزادسازی، وضعیت Busy/Available را درست تغییر می‌دهند. Boss در محیط سازمان همان وضعیت را می‌بیند. Telepresence و Robot Status از یک تابع وضعیت استفاده می‌کنند.
