# Organization navigation

## Before

Organization Owner/Admin saw the shared sidebar: Overview, Robot Operations, Remote Session, Robot Display, Members, Maps & locations, Invitations, Knowledge, Activity & maintenance, Settings. The organization detail page also had nested tabs. Some routes were still useful to shared flows.

## After

| Section | Route | Main function |
| --- | --- | --- |
| Organization Information | `/org/info` | Profile, departments, policies, logo |
| Users & Permissions | `/org/users` | Employees, activation, assignments |
| Robot Management | `/org/robots` | Registry pairing entry, fleet lifecycle |
| Robot Status | `/org/status` | Simulator status and Connect to Robot |
| Telepresence | `/org/telepresence` | Existing session interface |
| Billing & Support | `/org/billing-support` | Demo credits, tickets, assistant |

Boss global sidebar remains Overview, Organizations, Robot Management, Robot Monitoring, Settings. The Back to Boss control stays outside the six links. Account/profile/logout and demo notices remain outside functional navigation. User and public kiosk routes remain. A regular User reaches Billing & Support through the footer Support button; their existing sidebar stays role-specific and the credit ledger is hidden. Existing `/operations`, `/settings`, `/maps`, `/knowledge`, invitation and public routes remain available to authorized shared workflows, although omitted from the organization sidebar.
